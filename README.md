# 🐾 Clinique Fawn

Veterinary clinic management desktop app built with **C#, Windows Forms and ADO.NET** (SQL Server LocalDB).

## Features
- Role-based menus: Admin, Veterinarian, Secretary
- Owners and animals management, animal medical history
- Appointments and planning
- Consultations, vaccinations, medication stock
- Invoicing and dashboard

## Setup
1. Open `CliniqueVeterinaire.slnx` in Visual Studio.
2. Create the database with `SQLQuery.sql` (SQL Server LocalDB).
3. Update the `CliniqueVetDB` connection string in `App.config` to your local `.mdf` path.
4. Build and run.
